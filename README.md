This branch, "Main", is the production version of the Bot, and will be running the official code used on the server.

This is a Discord bot that I am developing and slowly updating as changes are requested for the Pine Valley Railway Discord for the #reports channel to help automate and standardize incident reports across its Railroader game server.

The following is how to register and use the bot yourself.
1. Register as a Discord Dev at https://discord.com/developers/home
2. Create a Bot application; the name you give the app will be what shows on the Discord server.
3. On the left side, change to "Installation", and under Guild Install:
	- Under Scopes, enable "bot"
  - Under Permissions, enable "Use Slash Commands"
  - Save changes
4. Go to OAuth2 and reset your "Client Secret"
5. Create a config.py file in the same directory as bot.py
6. Insert TOKEN="" and paste your token within the ""
7. Copy the bot install link & install the bot on a server you have admin access to.
8. Run the bot and your system
